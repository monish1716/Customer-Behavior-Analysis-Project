# 🛒 Customer Shopping Behavior Analysis

An end-to-end **Data Analytics Project** using **Python, SQL, Power BI, and Business Intelligence** to solve a real retail business problem.

---

## 📌 Business Problem Statement

A retail company wants to improve revenue, customer retention, and product strategy but lacks insights into:

- High-value customer segments  
- Subscription impact on repeat purchases  
- Discount effectiveness  
- Top-performing products  
- Customer shopping behavior  

This project uses data to generate actionable business recommendations.

---

## 🎯 Objectives

✅ Clean and transform raw data using **Python (pandas)**  
✅ Perform business analysis using **SQL**  
✅ Build an interactive **Power BI dashboard**  
✅ Create project documentation and presentation  
✅ Publish a portfolio-ready project on GitHub  

---

## 📂 Dataset Overview

- **3,900 Transactions**
- **18 Columns**
- Customer demographics, purchases, ratings, shipping, discounts, subscriptions


---

## 🐍 Data Cleaning (Python)

- Handled missing values  
- Standardized column names  
- Created `age_group` and purchase frequency features  
- Prepared clean dataset for SQL & dashboarding  

---

## 🛢 SQL Analysis

Answered key business questions:

- Revenue by gender & age group  
- Subscribers vs non-subscribers spend  
- Loyal / Returning / New customer segments  
- Top-rated & top-selling products  
- Discount dependency analysis  
- Shipping type spend comparison  

---

## 📊 Power BI Dashboard

Built an interactive dashboard to track:

- Revenue KPIs  
- Customer segments  
- Product performance  
- Discount trends  
- Subscription insights  


---

## 💡 Business Recommendations

- Increase subscriptions with exclusive benefits  
- Launch loyalty rewards for repeat buyers  
- Reduce unnecessary discounts  
- Promote top-rated products  
- Run targeted campaigns for valuable customer groups
